## Pourquoi Kuro

<CardGroup cols={2}>
  <Card title="Une API, des nœuds" icon="server">
    L'API pilote vos machines ; sur chacune, un daemon gère Docker. Le daemon ouvre lui-même sa
    connexion chiffrée vers l'API et n'expose aucune interface d'administration.
  </Card>
  <Card title="Des prefabs pour chaque jeu" icon="cubes">
    Un serveur se déploie depuis un prefab (image, réglages, fichiers, installation,
    sauvegarde). Écrivez les vôtres dans le Studio, testez-les sur un nœud de test, mettez à jour
    vos serveurs vers la nouvelle version.
  </Card>
  <Card title="Sécurisé par défaut" icon="shield-halved">
    TLS partout, mTLS entre l'API et les nœuds, conteneurs non root et limités, permissions fines
    et journal d'audit chaîné.
  </Card>
  <Card title="Ce qu'il faut, pas plus" icon="sliders">
    Console en direct, fichiers, sauvegardes, tâches planifiées, mods, quotas. Un nom DNS par
    serveur et un serveur MCP pour l'IA, si vous le souhaitez.
  </Card>
</CardGroup>

## Par où commencer

<Steps>
  <Step title="Installer l'API et le panel">
    Suivez [Installer l'API et le panel](/fr/install-api), puis créez le premier compte
    administrateur.
  </Step>
  <Step title="Ajouter un nœud">
    Enrôlez une machine qui fera tourner les serveurs : [Ajouter un nœud](/fr/add-a-node).
  </Step>
  <Step title="Déployer un serveur">
    Dans le panel : **Serveurs › Nouveau serveur**.
  </Step>
</Steps>
