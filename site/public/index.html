Install Kuro

Open source panel to run game servers on your own machines. One script installs the API and panel, or a node.

API and panel

curl -fsSL https://get.kuroctl.com/api | sudo bash -s -- --public-host panel.example.com --full

Node

Add the node in the panel first: it gives you the CA fingerprint and a one-time token.

curl -fsSL https://get.kuroctl.com/node | sudo -E bash -s -- --api https://panel.example.com:8443 --ca-fingerprint sha256:…

Read before running

The scripts are plain files: install.sh, api.sh, node.sh. Signed releases are on GitHub.
